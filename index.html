👑 Luarix Documentation

⚠️ IMPORTANT! ⚠️

Luarix is a premium script protection system. Your API key is tied to your account. Do not share your API key with anyone, or they will be able to manage your scripts and keys.

Top things to remember:

Content-Type header must be set to application/json in all of your API requests (handled automatically by our system).

Discord Bot Setup

To manage your keys and panels, you must invite our official Discord bot to your server and link your account.

  1. Go to the Dashboard and click Add to Discord.
  2. Authorize the bot and invite it to your server.
  3. Make sure the bot has the Manage Roles permission and its role is dragged above the Buyer Role in your server settings.
  4. In your server, run /link api_key: YOUR_API_KEY.
  5. Done! You can now use /setpanel and other commands.

How to Use Loaders

Once you create a script on the dashboard, you will receive a loader URL. It looks like this:

script_key="YOUR_KEY_HERE"; loadstring(game:HttpGet("https://luarix-eight.vercel.app/api/loader?id=YOUR_SCRIPT_ID"))()

If the script is Keyless, users do not need a key. If it requires a key, users must redeem a key via your Discord panel and paste it into the script_key variable.

/setpanel

Creates a beautiful control panel in the channel where you run the command.

  • project: Select your script from the dropdown.
  • manager_role: The role that is allowed to generate keys.
  • buyer_role: The role given to users when they redeem a key.

/createkey

Generates a new script key. You can set the duration in days, or type forever for a permanent key.

/whitelist & /blacklist

Use these to manually manage user access.

  • /whitelist: Gives a user instant access without needing a key.
  • /blacklist: Bans a user from a specific project with a custom reason and duration.

/masswhitelist

Instantly whitelists everyone who has a specific role (e.g., @Buyer) for a specific project.

Frequently Asked Questions (F.A.Q)

How do I get an API Key?

Log into the Dashboard. A free API key is automatically generated for you. If you want unlimited obfuscations, you can purchase a Basic or Premium plan.

My script says "HWID Mismatch". What do I do?

This means your key is locked to a different device. Go to the Discord panel and click the Reset HWID button, then run the script again.

How do I make my script free (Keyless)?

When creating or editing a project on the dashboard, toggle the Keyless Script switch to ON.
