👑 Luarix Documentation

⚠️ IMPORTANT! ⚠️

Luarix is a premium script protection system. We do not steal, view, or share your script sources. Your API key is tied to your account, do not share it.

How to Use Loaders

When you create a script on the dashboard, you get a clean loader string. This loader checks the HWID, validates the key, and delivers the encrypted code safely.

script_key="YOUR_KEY_HERE";
loadstring(game:HttpGet("https://getluarix.vercel.app/api/loader/YOUR_SCRIPT_ID"))()

If the script is set to Keyless, users do not need a key. They can just run the loadstring without the script_key variable.

Creating a Project

Click on the + Create Project button on the dashboard. Paste your Lua code, give it a name, and choose if you want it to be Keyless. The code will be securely encrypted and saved.

Managing Keys & HWID

Inside the Manage Project modal, you can generate 32-character secure keys. Users can redeem these via your Discord panel. If a user gets a new PC, you can click Reset HWID in the Manage Keys tab to allow them to run the script on their new device.

Kill Switch (Disable Script)

If you ever need to instantly disable a script (due to bugs, exploits, or leaks), go to the Manage Project modal and toggle the Kill Switch (Disable Script). Any user trying to execute the script will instantly be kicked with a "Script Disabled" message in the console.

Discord Bot Setup

To manage your keys and panels, invite our official Discord bot to your server and link your account.

  1. Go to Dashboard and click Add to Discord.
  2. Authorize the bot and give it Manage Roles permission.
  3. In your server, run /link api_key: YOUR_API_KEY.

Discord Commands

  • /setpanel - Creates a key redemption panel in the channel.
  • /createkey - Generates a new key for a specific project.
  • /whitelist - Manually whitelist a user without a key.
  • /blacklist - Ban a user from a specific project.
  • /masswhitelist - Instantly whitelist everyone with a specific role.

Frequently Asked Questions (F.A.Q)

How do I get an API Key?

Log into the Dashboard. A free API key is automatically generated for you. If you want more limits, you can purchase a Basic or Premium plan.

My script says "HWID Mismatch". What do I do?

This means your key is locked to a different device. Go to the Discord panel and click the Reset HWID button, or go to the Dashboard > Manage Keys and click Reset HWID, then run the script again.

Why is my script saying "Script Disabled"?

The owner of the script has toggled the Kill Switch in their dashboard. The script is temporarily offline. Contact the script owner for more information.

How do I make my script free (Keyless)?

When creating a project on the dashboard, toggle the Keyless Script switch to ON. Or click "Edit" on an existing project to toggle it.

Does Luarix steal or view my script?

Absolutely not. We encrypt your source code the moment it touches our servers. We do not have a "view source" option, and no staff member can read your Lua code.
